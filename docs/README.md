# docs

Documentación transversal del proyecto, la que no pertenece a una carpeta de
código en particular.

- `infraestructura.md`: contenedores, imágenes y entornos de ejecución.
- `integracion-continua.md`: qué revisa el pipeline en cada push y pull request.
- `prueba-flujo-completo.md`: lista de verificación manual de punta a punta
  para revisar la aplicación antes de publicarla.
